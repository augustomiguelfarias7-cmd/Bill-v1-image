# Bill v1 - Image Model

Experimental lightweight U-Net image model.

## Overview

Bill v1 is a small U-Net based model trained for educational purposes.  
It performs basic image reconstruction and generation at low resolution.

**Model details:**
- Architecture: U-Net
- Parameters: approximately 379,000
- Input / Output resolution: 64×64
- Trained on CPU with a small custom dataset

**Limitations:**
- Low resolution
- Experimental quality
- Not intended for production use

## Repository Structure

```
Bill-v1-image/
├── model/unet.py
├── weights/
│   └── parts/               # Split weight files
│       ├── bill_unet_part_01.bin
│       ├── ...
│       └── bill_unet_part_06.bin
├── examples/                # Sample outputs
├── inference.py
├── join_weights.py          # Script to reconstruct the full .pth
├── requirements.txt
└── README.md
```

## How to use

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Reconstruct the weights
The weights are split into smaller files. Run:
```bash
python join_weights.py
```
This will create `weights/bill_unet.pth`.

### 3. Run inference
```bash
python inference.py
```

## Examples

Sample images generated by the model are available in the `examples/` folder.
