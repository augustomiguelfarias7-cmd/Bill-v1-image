# Bill v1 - Image Model

Experimental lightweight U-Net based image model.

## Overview

Bill v1 is a small convolutional autoencoder / U-Net trained for educational and experimental purposes. It was trained on a limited set of images and is capable of basic reconstruction and generation with low resolution.

**Important limitations:**
- Very small model (~379k parameters)
- Trained on CPU with a small dataset
- Output quality is experimental and low-resolution
- Not intended for production use

## Structure

- `model/unet.py` – U-Net architecture
- `weights/bill_unet.pth` – Trained weights
- `examples/` – Sample outputs generated by the model
- `inference.py` – Simple script to load the model and run inference
- `upscale.py` – Basic post-processing / upscaling utility
